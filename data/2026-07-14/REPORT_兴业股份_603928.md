## 一、核心结论

兴业股份是国内铸造树脂细分领域龙头，冷芯盒树脂市占率连续多年稳居国内第一，自硬呋喃树脂位居行业第二。2025年受益下游制造业复苏，归母净利润同比大增150.6%。公司正依托树脂技术积淀向新能源、半导体、氢能储能三大高端赛道转型。

**但必须清醒认识到：**

1. **半导体光刻胶用酚醛树脂仅处于送样测试阶段**，尚未签订供货合同、暂未形成销售收入，存在产业化不确定性；
2. **当前估值显著高估**：市盈率43-60倍，远超化工行业17-29倍均值，存在明显的题材炒作泡沫；
3. **股东减持窗口已开启**：控股股东一致行动人已进入减持实施阶段；
4. **主力资金持续流出**：近5日主力净流出1.51亿元，散户接盘特征明显。

**整体评价：** 传统业务基本面改善，但短期估值泡沫化严重，博弈属性远大于长期投资价值。建议等待估值回调后再考虑布局。

## 四、三大业务板块拆解

### 4.1 核心基本盘：铸造材料（营收占比85-95%）

**产品矩阵：**
- 呋喃树脂（自硬砂铸造粘结剂）
- 冷芯盒树脂（精密铸造粘结剂）
- 碱性酚醛树脂
- 铸造涂料
- 氧化锆陶瓷过滤器
- 球化剂/孕育剂

**2025年业绩表现：**
- 合成树脂营收：10.78亿元（+3.68%）
- 铸造功能涂料营收：增速9.42%（高于整体营收增速）
- 合成树脂毛利率：15.41%（较2024年提升4.92个百分点）

**行业驱动因素：**

| 驱动因素 | 说明 |
|----------|------|
| **环保政策趋严** | VOCs、危废处置标准大幅提升，大量中小落后产能持续关停，行业集中度提升 |
| **制造业复苏** | 2025年汽车、工程机械、机床铸件需求稳定复苏 |
| **高端化转型** | 风电大型球墨铸件、轨道交通箱体铸件、核电大型铸件需求持续放量 |
| **绿色铸造** | 强制推行低甲醛、低VOC环保粘结剂，公司生物基呋喃树脂完全契合政策导向 |

**竞争格局：**
- 行业内仅**圣泉、兴业两家全国性龙头**
- 中小厂缺乏研发能力，只能做低端同质化产品
- 公司差异化技术壁垒持续拉开差距

**海外业务：**
- 2025年出口收入同比+37.64%
- 出口欧洲、东南亚、澳洲
- 海外毛利率达38.25%，显示国际竞争力较强

### 4.2 成长第二曲线：特种酚醛树脂

#### 4.2.1 锂电球形酚醛树脂（确定性小增量）

**产品定位：**
- 用于硅碳负极包覆、固态电池粘结剂
- 作为硅碳负极多孔碳前驱体材料，提升电池能量密度与循环寿命

**产业化进度：**
- 宁波基地2000吨新能源材料产线已投产
- **已通过宁德时代认证并批量供货**
- 切入动力电池、3C电池供应链
- 毛利率远高于传统树脂

**但必须理性看待：**
- 2000吨产线在化工行业中属于**细分小众配套级别**
- 整体营收体量**远小于铸造主业（10.78亿）**
- 属于"小增量"——已落地、有确定性，但体量有限

#### 4.2.2 半导体光刻胶用酚醛树脂（纯远期期权，尚无业绩贡献）

**核心定位：**
- 不做成品光刻胶，专攻光刻胶上游核心主体树脂（酚醛树脂）
- 主打i线/G线正性光刻胶必需的电子级高纯酚醛树脂（DUV光刻胶骨架主材）
- 当前国产化率**不足5%**，高度卡脖子

**研发进展：**

| 时间节点 | 进展 |
|----------|------|
| **2024年8月** | 官方正式披露研发成功，完成实验室配方、聚合工艺、提纯精制全流程打通 |
| **2024年四季度** | 南通生产基地建成百吨级半导体级高纯酚醛树脂中试生产线 |
| **2025年至今** | 持续向国内光刻胶厂商送样验证 |

**技术对标：**
- 分子结构、分子量分布、分散度对标日本住友、昭和电工
- 金属离子杂质（Na/K/Fe重金属）控制至ppb级
- 适配8寸/12寸晶圆G线（436nm）、I线（365nm）成熟制程光刻胶

**适用范围：**
- 主力适配：G/I线正胶（成熟制程光刻胶），即8寸分立器件、功率芯片光刻胶上游原料
- **暂时无法适配：KrF、ArF高端光刻胶**（高端胶用丙烯酸树脂、环烯烃树脂体系，不是酚醛体系）

**⚠️ 重要风险提示（公司多次公告强调）：**

| 风险点 | 说明 |
|--------|------|
| **产品状态** | 仅处于送样测试阶段，尚未签订任何供货合同、暂未形成销售收入 |
| **验证周期** | 晶圆厂端二次验证周期长，落地存在不确定性 |
| **营收占比** | 电子级酚醛树脂2025年度仅占营业收入的**0.12%**，几乎可以忽略 |
| **业绩贡献** | 完全未产生营业收入，对公司业绩暂无贡献 |
| **技术边界** | 不属于KrF/ArF/EUV高端光刻胶材料，锁定在G/I线光刻胶酚醛树脂 |

**商业化时间表（乐观预期）：**
- **短期（1-2年）**：以客户测试、小批量试样为主
- **中期**：测试通过后启动中试线扩产，主打性价比抢占国内成熟光刻胶原料市场
- **局限**：不涉足KrF/ArF/EUV高端光刻胶材料

#### 4.2.3 C919大飞机刹车片浸渍树脂

**产品定位：**
- 耐高温、高摩擦系数改性酚醛树脂
